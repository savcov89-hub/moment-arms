# Плечи силы и моменты — 3D-визуализатор

Интерактивное 3D-приложение: плечи силы и суставные моменты в упражнениях (приседания, становая, РТ, жимы лёжа, вертикальные тяги, маятниковый и ГАК-присед, жим ногами, ягодичный мост) с настройкой длины сегментов тела, трением и нагрузкой на мышцы в кг.

Один файл: `index.html` (без сборки). three.js 0.147 подключается с CDN jsDelivr — нужен интернет.

## Запуск
Открыть `index.html` в браузере или `python3 -m http.server`.

## GitHub Pages
Settings → Pages → Deploy from branch → `main` / root.
