# Формат данных по мышцам для приложения moment-arms

Владелец формата и интеграции: тред «анатомическая модель» (единственный, кто правит репозиторий).
Каждый регион кладёт в `/mnt/project-files/anatomy/<region>/` (`legs`, `trunk`, `arms`):
- `muscles.json` — массив мышц (формат ниже);
- `validation.json` — опубликованные моменты и силы для сверки;
- `sources.md` — список источников с номерами, на которые ссылаются `refs`.

## Системы координат сегментов (как в приложении)
Точка задаётся как `{seg, t, a, l}`:
- `t` — доля длины сегмента от проксимального сустава (0) к дистальному (1); можно <0 и >1;
- `a` — смещение вперёд (к передней/сгибательной стороне сегмента), м;
- `l` — смещение наружу (латерально, от средней линии тела), м. Минус — медиально.
`a` и `l` даются для эталона: мужчина 1,80 м, 80 кг. Приложение масштабирует их по росту.

| seg | начало (t=0) | конец (t=1) | «вперёд» (a>0) |
|---|---|---|---|
| `trunk` | середина между центрами тазобедренных суставов | середина между центрами плечевых суставов (≈0,52 м) | живот. Таз, рёбра и лопатка жёстко связаны с этим сегментом. Подвздошный гребень ≈ t 0,15; седалищный бугор ≈ t −0,12 |
| `thigh` | центр тазобедренного сустава | центр колена (≈0,44 м) | передняя поверхность бедра |
| `shank` | центр колена | центр голеностопа (≈0,44 м) | передняя поверхность голени |
| `foot` | пятка (задний край подошвы) | кончик носка; `a` = высота над подошвой | — |
| `ua` | центр плечевого сустава | центр локтя (≈0,33 м) | сторона бицепса |
| `fa` | центр локтя | середина хвата (≈0,34 м) | ладонная/сгибательная сторона |

Если точка лежит на лопатке или ключице, давайте её в `trunk` для нейтральной позы стоя, руки вдоль тела.

## Масштабирование под длины сегментов
В приложении меняются рост и длины голени, бедра, туловища, плеча, предплечья, стопы, ширина плеч и таза.
- `t` — доля длины сегмента, поэтому точки вдоль сегмента сами следуют за его длиной.
- `a` и `l` (поперечные смещения) приложение умножает на отношение длины сегмента к эталонной (как при масштабировании моделей OpenSim по сегментам). Если источник даёт другое правило, например масштаб поперечных размеров по росту или массе, опишите его в поле `scaling` у мышцы.
- Плечи силы приложение считает из геометрии пути при каждой позе. Таблицы `arm_cm` нужны, чтобы проверить, что путь даёт правильное плечо на эталоне. Если в литературе есть зависимость плеча от длины сегмента или роста (регрессии), положите её в `scaling`.
- `pcsa_cm2` для эталона 80 кг; приложение масштабирует его по массе тела в степени 2/3, если источник не говорит иначе.

## Мышца (`muscles.json`)
```json
{
  "id": "hamstrings_semimembranosus",
  "name_ru": "Полуперепончатая",
  "group_ru": "Задняя поверхность бедра",
  "path": [
    {"seg":"trunk","t":-0.12,"a":-0.03,"l":0.06},
    {"seg":"shank","t":0.06,"a":-0.02,"l":-0.03}
  ],
  "belly": [0.15, 0.80],
  "width_m": 0.05, "thickness_m": 0.04,
  "pcsa_cm2": 18.4, "opt_fiber_cm": 6.9, "pennation_deg": 15,
  "actions": [
    {"motion":"hip_ext","arm":{"angle_deg":[0,30,60,90],"arm_cm":[6.0,6.5,6.9,7.0]}},
    {"motion":"knee_flex","arm":{"angle_deg":[0,30,60,90],"arm_cm":[3.0,3.8,4.2,4.0]}}
  ],
  "refs": [1,3]
}
```
- `path`: начало, при необходимости промежуточные точки огибания, прикрепление. Первая точка — начало, последняя — прикрепление.
- `belly`: участок пути (доли длины), где мясистое брюшко; остальное сухожилие. Можно не указывать.
- `width_m`, `thickness_m`: ширина и толщина брюшка в нейтральной позе. Нужны для формы.
- `pcsa_cm2` обязательно: по нему делится момент между мышцами-синергистами.
- Широкие мышцы (дельтовидная, большая ягодичная, широчайшая, большая приводящая, трапециевидная) лучше давать несколькими пучками, каждый своим объектом.
- Одна сторона тела (левая). Правую приложение отражает само.

## Движения (`motion`) и углы
| сустав | motion | угол `angle_deg` |
|---|---|---|
| голеностоп | `ankle_plantar`, `ankle_dorsi` | тыльное сгибание, 0 = голень ⟂ стопе, + тыльное |
| колено | `knee_ext`, `knee_flex` | сгибание, 0 = прямая нога |
| тазобедренный | `hip_ext`, `hip_flex`, `hip_abd`, `hip_add` | сгибание, 0 = бедро на линии корпуса |
| поясница L5–S1 | `lumbar_ext`, `lumbar_flex`, `lumbar_latbend` | сгибание корпуса относительно таза, 0 = нейтраль |
| плечевой | `sh_flex`, `sh_ext`, `sh_abd`, `sh_add`, `sh_hadd`, `sh_habd` | подъём плеча (элевация), 0 = рука вдоль тела |
| локоть | `elbow_flex`, `elbow_ext` | сгибание, 0 = прямая рука |
Плечо силы в см, всегда положительное. Если в источнике одно значение — дайте один угол.

## Сверка (`validation.json`)
```json
{"exercise":"squat","condition":"глубина бедро ниже параллели, 1,0×вес тела","joint":"hip","motion":"hip_ext",
 "net_moment_Nm": 260, "per_kg_Nm": null, "muscle_force_N": {"glute_max": 1800}, "ref": 4}
```
Упражнения приложения: `squat`, `deadlift`, `rdl`, `bench`, `pulldown`, `hack`, `pendulum`, `legpress`, `bridge`. Подходят и другие условия (стояние, изокинетика), если явно указаны угол и нагрузка.
