# Плечи силы и моменты — 3D-визуализатор

Интерактивное 3D-приложение: плечи силы и суставные моменты в упражнениях (31 упражнение: приседания, становая, РТ, болгарские сплит-приседы, ягодичный мост; маятниковый и ГАК-присед, жим ногами, разгибание и сгибание ног, отведение бедра; жимы лёжа, жим гантелей на наклонной, сведение на блоках; вертикальные тяги, подтягивания, тяга штанги в наклоне, тяга гантели одной рукой, тяга горизонтального блока; жим стоя и сидя, махи гантелями, тяга к лицу; подъёмы на бицепс, «молотки», разгибание на блоке) с настройкой длины сегментов тела, трением и нагрузкой на мышцы в кг.

Один файл: `index.html` (без сборки). three.js 0.147 подключается с CDN jsDelivr — нужен интернет.

## Запуск
Открыть `index.html` в браузере или `python3 -m http.server`.
